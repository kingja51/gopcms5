PCMS 2026-001 사용자 사이트 와이어프레임 — 설계안 A~G

KRDS 공용 레이아웃 기반 학과 사이트. 7개 안 모두 IA·라우트·tb_menu 시드·보안·데이터 구조는 동일하며, 달라지는 것은 프레젠테이션 계층뿐입니다. {sc} = siteCode(학과코드 = 서브도메인, 예: ai·med·me).

서버 없이 이 파일을 브라우저로 직접 열면 됩니다. 각 카드를 클릭하면 해당 안의 목차로 이동하며, 안마다 layout · home · content · program · board · member · search-sitemap · common 8개 화면을 담고 있습니다. common은 공통 프로그램·보조 화면(학사일정 · 알림함 · 계정찾기 · 설문 · 민원 · 파일뷰어 · 오류 페이지) 묶음입니다. 메뉴 뎁스 원칙: 메뉴(GNB·LNB)는 3뎁스까지, 사이트맵은 4뎁스까지 출력 — 동일한 menuTree(depth 1~4)를 렌더 뎁스만 달리해 재사용하며, 4뎁스는 메뉴 대신 3뎁스 페이지 내 탭/필터로 진입합니다. 모든 안은 KRDS 규약(시맨틱 토큰 · htmx+순수 JS · 네이티브 <dialog>/<details> · CSP nonce) 범위 안에서 구현 가능합니다.
