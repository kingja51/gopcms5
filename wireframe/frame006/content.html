아코디언 = 네이티브 <details>/<summary> — JS 0줄. 첫 섹션만 open 기본. 섹션 구성 = 정본 메뉴 트리 3뎁스(인사말·비전·인재상·연혁)와 1:1 — "3뎁스 = 페이지 내 앵커/탭" 뎁스 규칙. 사이트맵·사이트맵의 3뎁스 링크 = 해당 섹션 앵커(#) 직결(details open 상태로 진입). 분절 단위는 관리자 콘텐츠(tb_content HTML)의 samples 서식(아코디언 블록)을 그대로 사용 — 콘텐츠 안 클래스는 _content-utility-safelist.html 범위만. 본문 HTML 은 OWASP Sanitizer 통과분(A안 동일). 데스크톱(≥1024px)에서는 details 를 CSS 로 항상 펼침 처리하지 않고 그대로 아코디언 유지 — 동작 일관성 우선.
