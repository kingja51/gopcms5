풀스크린 뷰어 — 다크 캔버스 + 상단 앱바 툴바(✕ 닫기 = history back, ⬇ 다운로드, ⤢ 원본 새 탭). 탭바 없음(몰입). 미리보기 대상 = 재인코딩 산출물만(원본 격리 디렉터리 직접 서빙 금지 — 6중 방어 파이프라인 통과분). 이미지 = <img> 즉시, PDF = self-host pdf.js(CDN 금지 — CSP self 제한) 또는 서버 페이지 이미지 변환 중 택1(PLAN 결정 대기). 미리보기 불가 형식(hwp·zip) = 아이콘 + 파일 정보 + 다운로드 버튼 폴백. 접근 권한 = 원문(게시글) 열람 권한 상속 — fileId 직링크도 서버 재검증.
