벤토 그리드 4컬럼(모바일 1컬럼 순차 적층, 태블릿 2컬럼). 히어로 카드만 SSR(LCP 보호), 나머지 위젯은 카드 껍데기만 SSR 하고 내용을 htmx 개별 로드 — 상단 위젯 hx-trigger="load", 폴드 아래(포토앨범·연구실)는 hx-trigger="revealed"(뷰포트 진입 시). 위젯 5개(공지·학사일정·날씨·포토앨범·연구실)가 각각 독립 요청이라 하나의 실패(타임아웃·5xx)는 그 카드의 "불러오지 못했습니다 ↻ 재시도" 폴백으로만 격리 — 페이지 전체가 깨지지 않음(htmx:responseError 위임 핸들러 1개, 외부 .js + CSP nonce). 데이터 소스 — 히어로: GET /api/v1/sites/{sc}/banners?location=MAIN_HERO(로테이션+⏸ 일시정지 필수, 접근성) / 공지: /bbs/ai/notice 위젯 조각 / 학사일정: /schedule/{master} 상위 N건 / 날씨: GET /weather/widget(외부 API 캐시 조각) / 포토앨범: GALLERY 게시판 /bbs/ai/photo 최신 3건 / 연구실: tb_lab(secondary) 랜덤 1건. 위젯 조각 URL 전부 tb_role_url_access 등록 필수(무매칭 DENY — 빠뜨리면 카드가 영원히 빈 폴백). 교수진은 홈 노출 제거(2026-07-10 요청) — GNB 구성원 › 교수진(/prg/faculty/ai)으로 접근, 바로가기 카드는 포토앨범으로 교체.
