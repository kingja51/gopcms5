PCMS 2026-001 사용자 사이트 와이어프레임 E안 (frame005)

동일한 KRDS 공용 레이아웃 체계·라우트를 유지하되 "포털형 벤토(bento) 대시보드"로 화면을 재구성한 대안 설계. 페이지 배경(웜그레이) 위에 radius 12px 카드 패널을 조합하는 것이 전 페이지 공통 문법 — 홈은 크기가 다른 위젯 카드의 벤토 그리드.

{sc} = siteCode(학과코드 = 서브도메인, 예: ai·med·me). URL이 진실, 세션은 편의. 라우트·보안·데이터 구조는 A안과 동일 — 달라지는 것은 프레젠테이션 계층뿐.

IA·라우트·tb_menu 시드는 A안과 동일 — 달라지는 것은 프레젠테이션 계층뿐. E안은 같은 menuTree 를 가로 GNB + 카드형 푸터 사이트맵으로 다르게 렌더할 뿐. 새 URL 은 tb_role_url_access 등록 필수(무매칭 DENY). 상세 트리는 frame001/index.html ② 참조. 메뉴 뎁스 출력 규칙(전 안 공통, tb_menu 최대 4뎁스) — 메뉴(GNB 드롭 카드)는 1~3뎁스까지만 노출, 4뎁스(전공필수·석사과정·휴·복학 서식 등)는 메뉴에 노출하지 않고 3뎁스 페이지 내 탭/필터로 처리. 사이트맵(/{sc}/sitemap)은 1~4뎁스 전체 전개. 데이터는 siteContext.menuTree 하나(depth 1~4 저장) — GNB 드롭 카드·푸터·사이트맵이 렌더 뎁스만 달리함(layout.html 드롭 카드 · search-sitemap.html 사이트맵 참조).
