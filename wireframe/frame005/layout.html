② 헤더 2단 — 로고 + 가로 GNB(1뎁스 5그룹) + 검색인풋 상시 노출(B안 오버레이·A안 아이콘과 다른 점 — 포털형 문법). 검색 제출 = GET /search?siteCode={sc}&keyword=. GNB 호버/포커스 시 2~3뎁스가 radius 12px 드롭다운 카드로 뜸(siteContext.menuTree 렌더 — 뎁스 규칙은 아래 출력 규칙 참조). ☰ = 모바일 전체메뉴 <dialog>. 스크롤 시 2단만 sticky.

출력 규칙(전 안 공통): GNB 드롭 카드는 1~3뎁스까지만 노출 — 2뎁스 = 굵은 링크 행, 3뎁스 = 들여쓰기 소항목(전임교원·학부·대학원…). 4뎁스(전공필수·석사과정·휴·복학 서식 등)는 메뉴에 노출하지 않고 3뎁스 페이지 내 탭/필터로 처리. 사이트맵(/{sc}/sitemap)만 1~4뎁스 전체 전개. 데이터는 siteContext.menuTree 하나(depth 1~4 저장) — GNB 드롭 카드·푸터·사이트맵이 렌더 뎁스만 달리함. 드롭다운도 카드 문법(radius 12px + 그림자) — 그룹별 개별 카드로 뜨며 전폭 메가메뉴 아님. 키보드 접근: 포커스 진입 시 열림, ESC 닫힘(외부 .js + CSP nonce, 인라인 핸들러 금지).

③ 페이지 타이틀 카드 — breadcrumb(위) + 제목(아래) + SUB_HERO 배너(우측 슬롯, GET /api/v1/sites/{sc}/banners?location=SUB_HERO). 배너 0건이면 우측 슬롯만 사라지고 카드는 유지 — 폴백 자연스러움. 홈은 이 카드 미출력(캐러셀 카드가 대신).
④ 본문 — layout:fragment="content" 페이지 배경(웜그레이) 위에 카드 패널을 그리드로 조합 홈 = 벤토 그리드 / 서브 = 본문 카드 + 보조 카드 컬럼 / 게시판 = 카드 스택
보조 카드 컬럼
④ E안에는 LNB 없음 — 같은 그룹 내 이동은 타이틀 카드 하단 칩 또는 우측 "연관 바로가기" 보조 카드가 담당. 위젯 카드는 각각 hx-get 개별 로드(hx-trigger="load"/"revealed") — 한 위젯의 htmx 실패는 해당 카드의 폴백 문구로만 격리되고 페이지 전체를 깨지 않음.
