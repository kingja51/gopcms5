인물 카드 = 사진 + 이름·직위 + 연락처 + 연구분야 칩. 데이터 = tb_faculty(secondary, site_code 스코프 — FAC_ 접두 PK). 전화·이메일은 MaskUtils 마스킹 출력(원문 노출 금지), 상세는 카드 클릭 → /prg/faculty/ai/{id}. 사진 없는 교원은 이니셜 플레이스홀더 — 카드 높이 유지. 모바일 1컬럼. 직원(/prg/staff/{sc})은 동일 골격에서 연구분야 칩 → 담당업무 텍스트로 치환 — 스킨 공유. 제네릭 /prg 라 학과 추가 시 복사 불필요(학과추가가이드), tb_role_url_access 에 /prg/** 규칙 기등록.

테이블 카드 — 카드 안에 테이블을 넣되 카드 radius 가 테이블 모서리를 감쌈(overflow:hidden). 연도/학기 셀렉트 변경 = hx-get 부분갱신(PageRequest 공통 파라미터). 계획서 보기 = PDF 뷰어(6중 방어 통과 파일, 재인코딩본 서빙). 데이터 = tb_syllabus(secondary, SYL_ 접두). 모바일은 행을 카드로 접는 스킨(테이블 → dl 변환).
