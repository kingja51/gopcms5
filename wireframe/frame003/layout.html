① 로고/사이트명 — tb_site 의 사이트명·테마 클래스(theme-*) 연동. 클릭 시 /{sc}/home. ② 사이드바 검색 인풋 — 상시 노출(C안 고유). submit → GET /search?siteCode={sc}&keyword= 일반 내비게이션(htmx 아님). 인라인 핸들러 금지 — form 기본 동작만 사용. ③ 메뉴 5그룹 아코디언 — 네이티브 <details>/<summary> 중첩으로 구현(KRDS 규약: 네이티브 요소 우선, JS 없이 동작): 1뎁스 그룹 → 2뎁스 → 3뎁스(2차 들여쓰기). 접힘 ▸ / 펼침 ▾ 표시, 현재 URL 이 속한 경로(교육 ▾ › 교과과정 ▾ › 학부)만 open 속성 SSR 렌더 — 스크롤스파이·펼침 저장 JS 불필요. 데이터는 siteContext.menuTree(tb_menu, site_code 스코프) 그대로 — A안 GNB·B안 메가메뉴와 동일 소스. nav 는 link_url 직접 사용. 현재 페이지 = active(청록 배경 + 좌측 램프). ③-1 메뉴 뎁스 출력 규칙(전 안 공통) — 사이드바 아코디언은 menuTree 1~3뎁스까지만 노출. 4뎁스(전공필수·전공선택, 석사·박사과정, 휴·복학/졸업 서식 등)는 메뉴에 노출하지 않고 3뎁스 페이지 내 탭/필터로 처리. 사이트맵(/{sc}/sitemap)만 1~4뎁스 전체 전개 — 데이터는 siteContext.menuTree 하나(depth 1~4 저장)이고 사이드바·사이트맵이 렌더 뎁스만 달리한다(search-sitemap.html 참조). ④ 하단 유틸 — 로그인/가입(로그인 후: 마이페이지/로그아웃), 🔔 알림함(/notification), ◐ 고대비(hc) 토글. 테마 토글은 외부 .js + CSP nonce, 이벤트 위임(closest('[data-action]')) 1회 등록. ⑤ 유틸바 — breadcrumb(menuTree 경로 역산) + 건양대·관련 사이트(타 학과 점프, 멀티사이트) + 🔍(사이드바 검색 포커스 이동). A안의 마스트헤드+breadcrumb 밴드 2개를 얇은 1줄로 통합. ⑥ 본문 — 사이드바는 position:sticky(뷰포트 고정)로 본문만 스크롤. SUB_HERO 배너는 유틸바 아래 슬림 밴드로 삽입(GET /api/v1/sites/{sc}/banners?location=SUB_HERO, 0건이면 미출력 — 폴백 자연스러움). 좋아요/신고 밴드는 contentId 있는 콘텐츠 페이지에서만(A안 동일). 푸터는 건양대 표준 공용(fragments/site-footer) — 콘텐츠 영역 하단에만 렌더(사이드바 아래 아님).
