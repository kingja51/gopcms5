메뉴는 3뎁스까지, 사이트맵만 4뎁스 — 동일 siteContext.menuTree 재사용(depth 1~4 저장), 사이드바·사이트맵이 렌더 뎁스만 달리한다. 회색 항목 = 4뎁스(전공필수·전공선택, 석사·박사과정, 휴·복학/졸업 서식): 메뉴 미노출 — 3뎁스 페이지 내 탭/필터로 진입. 3뎁스도 성격은 제각각(소개=페이지 내 앵커, 공지·연구성과=게시판 카테고리 필터, 교과과정=하위 페이지) — link_url 이 앵커/쿼리를 그대로 담는다. 사이트맵 = menuTree 를 그룹 컬럼으로 풀 확장 렌더(정적 SSR, JS 불필요) — C안에서는 "사이드바 아코디언을 전부 펼친 모습"의 확장판(+4뎁스)이라 별도 학습 비용 없음. display_yn=N 메뉴 제외, link_url 직접 사용. 사이드바 쪽도 이 페이지에선 전 그룹 open 렌더(우측과 호응 — 단 사이드바는 규칙대로 3뎁스까지만). 권한 표시 — 로그인 필요 메뉴(마이페이지 등)는 🔒 뱃지. 라우트 /{sc}/sitemap 은 tb_role_url_access ANONYMOUS 등록(무매칭 DENY). 45개 학과 사이트 전부 같은 템플릿 — 트리 내용만 site_code 시드 차이.
