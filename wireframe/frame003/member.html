독립 페이지(사이드바·GNB 없음) — 로그인은 사이트 무관 공통 화면(A·B안 동일). siteCode 쿼리로 복귀처·사이트명 표기만 바꿈("URL 이 진실"). 통합 로그인 = v_user_login VIEW(회원+관리자), 성공 시 changeSessionId() + PCMS_SID, maximumSessions(1). 보안 — CSRF: XSRF-TOKEN 쿠키 → 폼 히든 필드. 실패 5회/30분 잠금(잠금 시 남은 시간 안내), Bucket4j 레이트리밋. 실패 메시지는 원인 비특정("아이디 또는 비밀번호를 확인하세요"). 로그인 화면은 hx-history="false" + HTML no-store.

세로 스텝퍼(C안 고유) — 단계 전환 = hx-get 으로 우측 폼 영역만 부분갱신, 스텝퍼 상태 동기 갱신(hx-swap-oob). 뒤로가기 = 이전 단계 복귀되도록 hx-push-url, 입력값은 서버 세션 임시 보관(비밀번호 제외). ① 약관 = 필수/선택 구분 체크 + 전문 스크롤 박스. ③ 완료 = 가입 결과 + 로그인 유도. 검증 — 아이디 중복확인·이메일 인증 = hx-get/post 인라인 피드백. 비밀번호 정책 서버 검증(클라 안내는 보조). PII(이메일·전화)는 @Encrypt(AES-256-GCM) 저장 + log_privacy 기록. 회원 인가는 tb_member_role 미사용 — AUTHENTICATED + user_type=MEMBER.

카드 대시보드(C안 고유) — A안(좌측 메뉴)·B안(상단 탭)과 달리 별도 내비 없이 카드 6장이 곧 메뉴. 각 카드 → 상세 화면(profile·password·withdraw)은 콘텐츠 영역 교체(일반 내비게이션). 진입 게이트: /member/mypage/** 는 재인증(비밀번호 확인) 세션 플래그 필요 — 미통과 시 재인증 카드 선노출. tb_role_url_access 에 AUTHENTICATED 등록. 표시 규칙 — 이메일·전화 MaskUtils 마스킹, 원문은 수정 화면에서 재인증 후에만. 탈퇴 = soft-delete(delete_yn) → 생명주기 배치(휴면·퍼지)로 파기, tb_pii_purge_log 기록. 알림 토글 = hx-post 즉시 저장 + 조각 갱신. 마이페이지 전체 hx-history="false" + no-store(뒤로가기 민감).
