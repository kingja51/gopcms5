2-pane(C안 고유) — 목록 행 = 버튼: hx-get="/bbs/ai/notice/{articleId}/pane" hx-target="#preview-pane" hx-push-url="/bbs/ai/notice/{articleId}" — 우측만 부분갱신하면서 URL 은 상세 딥링크로 유지(새로고침/공유 시 서버가 같은 2-pane 을 SSR). 선택 행 = 청록 램프 강조. ↑↓ 키보드 이동(외부 .js 이벤트 위임, htmx:load 멱등). 초기 진입 시 우측 pane 은 "글을 선택하세요" 빈 상태(articleId 딥링크 진입이면 해당 글). 목록 pane — 검색(300ms debounce)·정렬·페이징 전부 hx-get 부분갱신(hx-target 목록만, hx-history="false"). 고정공지 상단 유지. 읽은 글은 제목 굵기 400 처리. 카테고리 칩(학사·장학·취업) = menuTree 3뎁스와 동일 항목 — 사이드바 3뎁스 클릭 = ?cat= 딥링크(같은 필터 프리셋). 연구성과(/bbs/{sc}/pub)의 논문·특허·기술이전도 같은 카테고리 문법. ↗ 전체화면 = 1단 상세 페이지(/bbs/{sc}/{bbsCode}/{articleId}?view=full)로 전환 — 인쇄·긴 글 대응. 상세 pane — 본문 = OWASP Sanitizer 통과 HTML, 첨부 다운로드 = 6중 방어 자원. 댓글 등록/삭제 = hx-post → 댓글 블록만 갱신, 작성자 마스킹(MaskUtils). 좋아요/신고·수정/삭제 = CUD 규약(try-catch + log + HX-Redirect). 쓰기 권한은 tb_role_url_access + 게시판 권한(bbs_master) 2중 확인. 스킨 변형 — GALLERY: 목록 pane 이 썸네일 2열 그리드 / FAQ: pane 분할 없이 <details> 아코디언 1단 / QNA: 목록에 답변대기·완료 뱃지 / FILE: 미리보기 pane 에 첨부 목록 우선 / YOUTUBE·PDF: 우측 pane 이 플레이어/뷰어. 골격(목록 pane + 상세 pane) 공유.

모바일(~767px) — 같은 URL 에서 pane 분할 CSS 해제: 목록 행 클릭이 일반 내비게이션(전체 페이지 상세)으로 동작하도록 hx-get 을 데스크톱 미디어쿼리 조건에서만 활성(htmx:configRequest 에서 판별, 외부 .js). 상세 → "← 목록" 은 검색·페이지 쿼리 보존 복귀. 서버는 view 파라미터/HX-Request 헤더로 pane 조각 vs 전체 페이지를 구분 렌더 — 컨트롤러 1개, 뷰 2벌.
