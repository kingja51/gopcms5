필터 패널(C안 고유) — 체크/칩 변경 = form 전체를 hx-get="/prg/faculty/ai/grid" 부분갱신(hx-target 카드 그리드, hx-include 필터폼, 300ms debounce). change 이벤트는 document 위임 1회 등록. 선택 필터는 그리드 상단 제거형 칩으로 재표기. hx-push-url 로 필터 상태 URL 반영(공유 가능) — hx-history 는 기본 유지. 데이터 — tb_faculty(secondary DB, FAC_ 접두 PK, site_code 스코프): /prg/faculty/{sc} 제네릭 컨트롤러가 다학과 공용(새 학과 추가 시 복사 불필요, 시드만). 이메일·전화는 MaskUtils 마스킹 출력. 카드 클릭 → 상세 <dialog>(hx-get 조각) — 연구실적·담당과목 포함. 전공분야 파라미터는 전량 #{} 바인딩(매퍼 3벤더 XML 동기).
