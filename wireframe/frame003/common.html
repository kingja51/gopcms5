사이드바 프레임 유지 여부 — 404·403 은 사이드바 프레임 유지(menuTree 렌더 가능, 사용자가 길을 잃지 않게 내비 제공). 5xx 는 사이드바 없는 최소 독립 페이지 — DB 장애 시 menuTree 조회 자체가 실패할 수 있어 정적 조립(인라인 최소 스타일, 외부 자원 무의존)으로 렌더. 403 — tb_role_url_access 무매칭 DENY 정책상 "새 URL 을 만들고 접근 규칙 등록을 빠뜨린" 개발 실수도 403 으로 나타남 — 사용자 문구는 권한 안내로 통일하되, 서버 로그에 무매칭 DENY 원인(요청 URL·매칭 실패)을 구분 기록해 디버깅 단서 제공. 비로그인 + 인증 필요 URL 은 403 대신 로그인 리다이렉트 우선. 404 — 존재하지 않는 siteCode(서브도메인)도 404 계열 처리(사이트 열거 방지). 5xx — 스택트레이스·내부 경로 절대 비노출, 오류 코드(로그 상관 ID)만 표기. htmx 요청 중 오류 = HX-Retarget 대신 전체 리다이렉트(부분 삽입으로 오류 화면 조각이 끼어드는 것 방지, htmx:responseError 위임 1건).
