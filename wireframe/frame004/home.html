도트 섹션 내비(스크롤스파이)
현재 섹션 = 채운 도트, 클릭 = 해당 앵커로 스크롤
각 섹션 id="sec-hero…sec-cta" 앵커 + IntersectionObserver 스크롤스파이(외부 .js + nonce, 순수 JS — 프레임워크 금지). 클릭 이동은 이벤트 위임 closest('[data-action="dotnav"]'), smooth 스크롤은 prefers-reduced-motion 시 instant. 모바일은 도트 내비 숨김.
