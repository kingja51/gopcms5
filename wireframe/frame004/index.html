PCMS 2026-001 사용자 사이트 와이어프레임 D안 (frame004)

동일한 KRDS 공용 레이아웃 체계·라우트를 유지하되 원페이지 풀블리드 매거진/에디토리얼로 화면을 재구성한 대안 설계. 투명 오버레이 헤더 + 풀스크린 오버레이 메뉴 + 협폭(720px) 에디토리얼 본문이 골격.

{sc} = siteCode(학과코드 = 서브도메인, 예: ai·med·me). 라우트·보안·데이터 구조는 A안과 동일 — 달라지는 것은 프레젠테이션 계층뿐.

네 안 모두 KRDS 규약(시맨틱 토큰·htmx+순수JS·네이티브 <dialog>/<details>·CSP nonce·이벤트 위임) 안에서 구현 가능. D안의 거대 타이포도 KRDS 타이포 토큰 text-display-* 범위에서 구현 — raw text-6xl 금지는 D안에서도 동일. 풀스크린 오버레이 메뉴는 siteContext.menuTree 재사용 — 추가 데이터 불필요. 출력 규칙(전 안 공통): 메뉴는 1~3뎁스까지만 노출, 사이트맵만 1~4뎁스 전체 전개 — 4뎁스는 3뎁스 페이지 내 탭/필터로 처리.

IA·라우트·tb_menu 시드(최대 4뎁스)는 A안과 동일 — 달라지는 것은 프레젠테이션 계층뿐. D안은 같은 메뉴 트리를 풀스크린 오버레이/거대 타이포 사이트맵으로 다르게 렌더할 뿐. 메뉴 뎁스 규칙: 풀스크린 오버레이 메뉴 = 1~3뎁스(4뎁스는 3뎁스 페이지 내 탭/필터), 사이트맵 = 1~4뎁스 전체 전개 — siteContext.menuTree 하나로 렌더 뎁스만 달리함. 새 URL 은 tb_role_url_access 등록 필수(무매칭 DENY) — 상세 트리는 frame001/index.html ② 참조.
