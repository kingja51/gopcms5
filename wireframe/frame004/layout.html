③ 페이지 히어로 — 거대 타이포 제목(text-display-lg) + 한 줄 소개 + breadcrumb 미니 텍스트를 하나의 밴드로 통합(A안 breadcrumb 밴드·B안 타이틀 밴드 대체). SUB_HERO 배너(GET /api/v1/sites/{sc}/banners?location=SUB_HERO)는 히어로 배경 이미지로 흡수 — 배너 0건이면 브랜드 단색/그라디언트 폴백이라 레이아웃 붕괴 없음. 한 줄 소개는 tb_menu 설명 필드 또는 콘텐츠 요약.
④ 본문 — layout:fragment="content" 풀블리드 섹션 스택(홈·연구실 밴드·지도) 또는 협폭 720px 에디토리얼 컬럼(읽기 페이지) LNB 없음 — 같은 그룹 내 이동은 하단 이전/다음 내비 + 풀스크린 메뉴가 담당
④ 본문 2형: 풀블리드형(섹션이 캔버스 좌우 끝까지, 면 교차로 리듬) / 협폭형(.narrow = max-width 720px 센터 — 에디토리얼 읽기 폭). 박스 구분은 선 대신 면(옅은 채움 bg-surface-alt 교차) + 그림자 최소. radius 는 KRDS 상한 12px 준수.
