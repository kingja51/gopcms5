PCMS 2026-001 사용자 사이트 와이어프레임 A안 (frame001)

KRDS 공용 레이아웃(front/layouts/KRDS/krds.html) 기반 학과 사이트 기준. 사이트별 차이는 템플릿 CSS 1장(/tmpl/css/krds/*.css)과 테마 클래스뿐이며 페이지 골격은 전 사이트 공통.

아래 {sc} = siteCode(학과코드 = 서브도메인, 예: me·cse·ai). URL이 진실, 세션은 편의.

① 와이어프레임 목차
파일화면대표 라우트
layout.html공용 레이아웃 해부도 (마스트헤드·GNB·breadcrumb·푸터)전 페이지 공통 프레임
home.html사이트 홈 (히어로·바로가기 타일·공지·포토앨범)/{sc}/home
content.html콘텐츠 페이지 (학과소개·오시는길)/{sc}/about · /{sc}/location
program.html프로그램 페이지 (교수진·직원·연구실·수업계획서)/prg/{program}/{sc}
board.html게시판 목록 + 상세(댓글·좋아요/신고)/bbs/{sc}/{bbsCode}
member.html회원 (로그인·가입 3단계·마이페이지)/member/**
search-sitemap.html통합검색 · 사이트맵/search · /{sc}/sitemap

각 파일은 브라우저에서 직접 열면 됨(서버 불필요). 회색 실선 = 정적 마크업, 파란 점선 = htmx/JS 동적 슬롯, 파란 주석 = 구현 메모.
② 정보구조(IA) — 학과 사이트 표준 메뉴 5그룹 (정본 트리, 최대 4뎁스)
/{sc}/home ─────────────────────── 홈(캐러셀 담당, SUB_HERO 미출력)
├─ 소개 (1뎁스 GROUP)
│  ├─ 학과소개 → /{sc}/about (CONTENT)
│  │  └─ 인사말 · 비전·인재상 · 연혁 (3뎁스 = 페이지 내 앵커/탭)

│  │  └─ 전임교원 · 겸임·초빙 · 명예교수 (3뎁스 = 목록 필터)
│  └─ 직원   → /prg/staff/{sc}
├─ 교육 (GROUP)
│  ├─ 교과과정   → /{sc}/curriculum
│  │  ├─ 학부 (3뎁스)
│  │  │  └─ 전공필수 · 전공선택 (4뎁스 = 페이지 내 탭)
│  │  └─ 대학원 (3뎁스)
│  │     └─ 석사과정 · 박사과정 (4뎁스 = 페이지 내 탭)
│  ├─ 수업계획서 → /prg/syllabus/{sc}
│  └─ 학사일정   → /schedule/{master} (일정 프로그램)

└─ 커뮤니티 (GROUP)
   ├─ 공지사항 → /bbs/{sc}/notice (NOTICE 타입)
   │  └─ 학사 · 장학 · 취업 (3뎁스 = 카테고리 필터)
   ├─ 학과소식 → /bbs/{sc}/news
   ├─ 세미나   → /bbs/{sc}/seminar
   └─ 자료실   → /bbs/{sc}/archive (FILE 타입)
      ├─ 학사서식 (3뎁스)
      │  └─ 휴·복학 서식 · 졸업 서식 (4뎁스 = 카테고리)
      └─ 강의자료 (3뎁스)
뎁스 출력 규칙(전 안 공통) — 메뉴(GNB·드롭다운)는 1~3뎁스까지만 노출, 4뎁스는 메뉴에 노출하지 않고 3뎁스 페이지 내 탭/필터로 처리(layout.html 드롭다운 해부도). 사이트맵은 1~4뎁스 전체 전개(search-sitemap.html). 데이터는 siteContext.menuTree 하나(depth 1~4 저장) — GNB·사이트맵이 렌더 뎁스만 달리함. 메뉴는 tb_menu(site_code 스코프) 시드가 정본 — nav 는 link_url 을 직접 사용. 새 URL 은 tb_role_url_access 등록 필수(무매칭 DENY).
