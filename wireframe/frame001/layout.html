KRDS 템플릿 13종이 이 레이아웃 1개를 공유. 템플릿별 차이는 CSS 1장(--tpl-chrome·--brand-* 램프)뿐. 모든 사용자 페이지가 이 프레임 안의 본문 슬롯만 갈아끼움(Thymeleaf layout:decorate).

② GNB — siteContext.menuTree(tb_menu, depth 1~4 저장) 렌더. 활성 표시 = 색+보더 병행(currentUri prefix 매칭), 호버 열림 = 배경 강조(위 「교육」). 통합검색 = /search?siteCode={sc} + 자동완성(search-autocomplete.js). 뎁스 출력 규칙(전 안 공통) — 메뉴(GNB·드롭다운)는 1~3뎁스까지만 노출: 3뎁스가 있는 2뎁스(교과과정 ›)만 플라이아웃 2열 확장. 4뎁스(전공필수·전공선택, 석사·박사과정, 휴·복학/졸업 서식)는 메뉴에 노출하지 않고 3뎁스 페이지 내 탭/필터로 처리. 사이트맵(/{sc}/sitemap)만 1~4뎁스 전체 전개 — 동일 menuTree, 렌더 뎁스만 다름.
SUB_HERO 배너 (서브페이지 전용 슬롯)
③ 서브 비주얼 — sub-hero.js 가 GET /api/v1/sites/{sc}/banners?location=SUB_HERO 로 클라이언트 렌더. 홈(/{sc}/home)은 캐러셀 담당이라 슬롯 미출력, 배너 없으면 빈 슬롯(페이지 자체 헤더 폴백).
