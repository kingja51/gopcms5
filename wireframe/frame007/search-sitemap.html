메뉴는 3뎁스까지, 사이트맵만 4뎁스 — 동일 menuTree 재사용. 사이트맵 페이지 = siteContext.menuTree(depth 1~4 저장) 전체를 5그룹 격자로 1~4뎁스 전개 — GNB 전체 펼침 패널(1~3뎁스)·푸터 사이트맵(1~2뎁스 요약)과 동일 데이터·동일 조각 로직(렌더 뎁스만 다름). 4뎁스 링크는 3뎁스 페이지의 해당 탭/필터로 이동(예: 전공필수 → /{sc}/curriculum?track=required). 3뎁스 성격은 정본 트리 ※ 표기 그대로 — 학과소개 하위 = 페이지 내 앵커/탭, 연구성과·공지사항 하위 = 게시판 카테고리 필터. 그룹 헤더 = h2, 하위 = 중첩 ul/li 시맨틱 마크업(스크린리더 목차 역할). 표시 여부 = tb_menu 노출 플래그(비공개 메뉴 제외).
