③ 풀폭 GNB — 1뎁스 5그룹 상시 노출, 호버/포커스 시 모든 그룹의 하위메뉴가 한 번에 펼쳐지는 전체 펼침형 패널(공공 표준 패턴). 패널 안은 2뎁스 리스트 + 3뎁스 들여쓰기(· 표기)로 표현. 개별 드롭다운이 아니라 패널 1장이라 키보드 탐색이 단순(Tab 순차 이동, ESC 닫기) — 1뎁스 트리거에 aria-expanded 상태 반영, 마우스 없는 사용자를 위해 포커스 진입 시에도 열림(KWCAG 2.1 키보드 접근성). 데이터 = siteContext.menuTree(tb_menu, site_code 스코프) — 푸터 사이트맵·사이트맵 페이지와 동일 소스. 현재 그룹 = on(흰 밑줄). 모바일은 아코디언 <details> 전환. 메뉴 뎁스 출력 규칙(전 안 공통) — 메뉴(GNB 패널·LNB)는 1~3뎁스까지만 노출. 4뎁스(전공필수/전공선택·석사/박사과정·휴복학/졸업 서식)는 메뉴에 넣지 않고 3뎁스 페이지 내 탭/필터로 처리. 사이트맵 페이지만 1~4뎁스 전체 전개, 푸터 사이트맵은 1~2뎁스 요약 — 전부 siteContext.menuTree 하나(depth 1~4 저장)를 렌더 뎁스만 달리해 재사용.

LNB도 3뎁스까지만 — 4뎁스는 3뎁스 페이지 내 탭/필터(예: 교육 › 교과과정 › 학부 페이지의 전공필수/전공선택 탭 — content.html 참조).
