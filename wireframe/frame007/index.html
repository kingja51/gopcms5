PCMS 2026-001 사용자 사이트 와이어프레임 G안 (frame007)

"공공기관 정석 3단 헤더 + 좌 LNB 3뎁스 + 우측 플로팅 퀵메뉴" — KRDS 가이드라인에 가장 보수적으로 충실한 안. 유틸바·로고+통합검색·풀폭 GNB(전체 펼침형 패널)의 3단 헤더, 서브페이지는 SUB_HERO 타이틀 밴드 + 좌 LNB + breadcrumb 유틸, 푸터는 풀 사이트맵형.

{sc} = siteCode(학과코드 = 서브도메인, 예: ai·med·me). 라우트·보안·데이터 구조는 A안과 동일 — 달라지는 것은 프레젠테이션 계층뿐.

① G안 핵심 차이 (vs A~F안)
항목A~F안 요약G안 (frame007)
글로벌 내비 A=GNB 밴드+호버 드롭다운 / B=콤팩트 헤더+☰ 메가메뉴 / C=좌측 사이드바+2-pane / D=풀블리드 원페이지 에디토리얼 / E=포털형 벤토 카드 / F=모바일 퍼스트 하단 탭바 3단 헤더 — ①유틸바(관련사이트·글자크기·고대비·언어) ②로고+통합검색 인풋+로그인/알림 ③풀폭 GNB 5그룹, 호버 시 전체 펼침형 패널(모든 그룹 2~3뎁스 하위메뉴 동시 전개 — 4뎁스는 메뉴 미노출)
서브페이지 구조 A=본문 1단 와이드 / B=타이틀 밴드+LNB 2단 / C=2-pane 고정 / D=원페이지 스크롤 / E=카드 대시보드 / F=단일 컬럼 스택 SUB_HERO 배경 타이틀 밴드 + 좌 LNB 2~3뎁스 트리(현재 위치 강조·상위 접기) + 본문 우상단 breadcrumb·인쇄·URL복사 유틸 + 우측 플로팅 퀵메뉴(5개+TOP)
홈 A=풀폭 캐러셀+타일 / B=스플릿 히어로+탭 위젯 / C=사이드바 옆 피드 / D=매거진 커버 / E=벤토 그리드 / F=앱형 카드 스트림 풀폭 히어로 캐러셀(재생/정지 컨트롤) → 학과 소식 2컬럼(공지 테이블+갤러리 썸네일) → 바로가기 배너 4열 → 학사일정 미니 캘린더+정보 패널 → 하단 배너존 롤링
게시판 A=테이블형 / B=카드형 / C=리스트+미리보기 pane / D=피드형 / E=카드 그리드 / F=무한스크롤 카드 정석 테이블형(번호·제목·첨부·작성자·등록일·조회) + 상단 공지 고정행 + 기간·범위 셀렉트 검색폼 + 숫자형 페이징. 상세 = 제목 헤더 테이블+첨부 용량 표기+이전/다음 행
검색 A=독립 결과 페이지 / B=전체화면 오버레이 / C=사이드바 인라인 / D=커맨드 팔레트 / E=검색 위젯 카드 / F=검색 탭 헤더 중앙 상시 인풋 → 결과 페이지(재검색 폼+범위 탭 전체/콘텐츠/게시글/파일+인기검색어 사이드 박스)
마이페이지 A=좌측 메뉴+대시보드 / B=상단 탭+카드 / C=사이드바 통합 / D=프로필 히어로 / E=위젯 보드 / F=설정 리스트 좌 LNB(회원정보·비밀번호·내 글·알림함·회원탈퇴) + 본문 폼 테이블 — 서브페이지와 동일 프레임의 정석형
G안의 지향점 = 낯섦 0%. 대학·관공서 사용자가 이미 학습한 관습(3단 헤더·좌 LNB·테이블 게시판·플로팅 퀵메뉴)을 그대로 재현해 학습 비용을 없앤다. KRDS 규약(시맨틱 토큰·htmx+순수JS·네이티브 요소 우선·CSP nonce·radius ≤12px) 안에서 구현 — G안은 radius 0~6px 로 더 보수적으로 잡는다.
