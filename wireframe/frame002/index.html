PCMS 2026-001 사용자 사이트 와이어프레임 B안 (frame002)

동일한 KRDS 공용 레이아웃 체계·라우트를 유지하되 화면 구성을 다르게 잡은 대안 설계. A안(../frame001/index.html)과 나란히 놓고 비교·선택하는 용도.

{sc} = siteCode(학과코드 = 서브도메인). 라우트·보안·데이터 구조는 A안과 동일 — 달라지는 것은 프레젠테이션 계층뿐.

항목A안 (frame001)B안 (frame002)

메뉴 뎁스 출력 규칙(전 안 공통) — 메뉴(메가메뉴·LNB)는 1~3뎁스까지만 노출, 4뎁스(전공필수·석사과정·휴·복학 서식 등)는 3뎁스 페이지 내 탭/필터로 처리. 사이트맵은 1~4뎁스 전체 전개. 데이터는 siteContext.menuTree 하나(depth 1~4 저장) — 메가메뉴·LNB·사이트맵이 렌더 뎁스만 달리함. IA·라우트·tb_menu 시드는 변경 없음 — B안은 같은 메뉴 트리를 메가메뉴/LNB 로 다르게 렌더할 뿐. 상세 트리는 frame001/index.html ② 참조.
