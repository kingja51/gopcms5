403 주의 — tb_role_url_access 는 무매칭 DENY: 새 URL 을 추가하고 접근 규칙 등록을 빠뜨리면 정상 화면도 403 이 뜬다(가장 흔한 실수). 이 화면에서 원인을 짐작할 수 있게 개발(local) 프로파일에서만 "매칭 규칙 없음" 힌트 노출, 운영은 일반 문구만. 404/403 = 공용 레이아웃 유지(헤더·푸터 포함, 사이트 이탈 방지). 5xx = 레이아웃 렌더 자체가 실패할 수 있어 정적 독립 HTML. 오류 코드 = 로그 상관키(스택·내부 정보 화면 노출 금지 — errorId 로만 추적). 오류 페이지도 no-store.
