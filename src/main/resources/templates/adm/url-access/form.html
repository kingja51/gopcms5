Ant 표기 — * 는 한 세그먼트, ** 는 하위 전체. 예: /*/member/**

ALL = 메서드 무관. 조회는 공개·쓰기는 인증처럼 나눌 때 씁니다.

사이트 규칙은 같은 순위의 전역 규칙보다 먼저 적용됩니다.

작을수록 먼저. 구체적인 패턴에 더 작은 값을 주세요.

판정

PERMIT_ALL 공개 · AUTHENTICATED 로그인 필요 · ROLE 특정 역할 · IP_ONLY 허용 IP · DENY 차단

비우면 유형 무관. 쉼표로 여러 개(예: ADMIN,EMPLOYEE).

상위 역할을 가진 계정은 자동으로 통과합니다(계층 전개 결과와 교집합으로 판정).
