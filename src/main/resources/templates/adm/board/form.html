기본

URL 에 그대로 나갑니다 — /bbs/{사이트코드}/{게시판코드}. 소문자로 시작하는 2~50자(소문자·숫자·_·-). 사이트 안에서 유일해야 합니다.

유형이 사용자 화면을 정합니다(front/board/{유형}/…). 나중에 바꾸면 같은 글이 다른 형태로 보입니다.

운영자용 메모입니다. 화면에 나가지 않습니다.

권한

ALL = 비로그인 포함 누구나. 공지·보도자료는 보통 ALL 입니다.

비로그인 작성은 지원하지 않습니다 — 스팸과 추적 불가 문제 때문입니다.

글에 붙는 첨부의 기본 공개 범위입니다. 공지글은 이 값과 무관하게 항상 공개됩니다(공지는 누구나 받아야 하므로). OWNER_PRIVACY 는 민원글처럼 본인만 열어야 할 때 씁니다 — 최고 관리자도 자동으로 통과하지 않습니다.

본문·작성

개 MB

업로드 자체의 상한(형식·크기)은 시스템 설정이 따로 강제합니다. 여기 값은 이 게시판의 추가 제한입니다.

통합 게시판

여러 게시판의 글을 한 화면에 모아 보여주는 읽기 전용 게시판이 됩니다. 게시판 ID 를 쉼표로 잇습니다(최대 24개). 통합 게시판을 다시 통합 대상으로 넣을 수는 없습니다 — 목록 질의가 재귀가 되기 때문입니다.
