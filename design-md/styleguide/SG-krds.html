0. 사용법 — 빌드 & 로드

Tailwind v4 CLI 빌드

이 가이드 페이지 자체가 아래 명령의 산출물(SG-krds-output.css) 하나만 로드한다.

# 전역(실서비스) — src/krds.css → dist/krds.css
npx @tailwindcss/cli -i ./src/krds.css -o ./dist/krds.css --minify

# 스타일가이드(이 페이지) — design-md/styleguide 에서
npx @tailwindcss/cli -i ./SG-krds-input.css -o ./SG-krds-output.css

실서비스 레이아웃 <head> 로드 순서

<link rel="stylesheet" href="/css/output.css"/>   <!-- KRDS 토큰+유틸+프리셋 (단일 파일) -->
<!-- 테마: <html class="theme-indigo"> · 고대비: <html class="hc"> — 사이트 설정 연동 -->

2. 타이포그래피 — KRDS 스케일 토큰만 사용

디스플레이 MD — 히어로 .text-display-md (44px)

헤딩 MD — 소섹션 .text-heading-md (24px)

헤딩 SM — 카드 제목 .text-heading-sm (19px)

본문 LG — 리드 문단 .text-body-lg (19px)

본문 MD — 기본 읽기 텍스트 .text-body-md (17px)
